# 产品需求文档（PRD）正文摘要

> 完整条文以 [docs/PRD_Before1800_RevisedV2.md](docs/PRD_Before1800_RevisedV2.md) 为准。以下为便于仓库首页阅读的结构化摘录。

## 1. 概述

### 一句话概念

你扮演林最信任的朋友，实际上是参与制造他人生骗局的演员。你决定在导演 18:00 回岗前，带他发现并验证世界的漏洞，承认自己的隐瞒，帮助他自愿离开。

### 目标用户与体验价值

- **目标用户**：喜欢悬疑探索、叙事解谜和角色互动的玩家。  
- **核心玩法**：寻找异常、选择验证方法、解释证据、回应林的担忧。  
- **体验问题**：凭什么相信世界真实？被安排的生活中感情是否仍有意义？谁有权决定离开？

### 核心矛盾

> **「我一直在骗你，现在你还能相信我吗？」**

事实验证与信任修复分别推进：证据越充分，事实争论越少；情感顾虑仍需交流。

## 2. 故事与世界观

- 林把片场当作真实世界；玩家开场便知道真相（信息优势，非俯视镜头）。  
- 首版：**第一人称探索**。  
- **休播日**：导演暂时离岗，设备仍运行；**18:00** 恢复控制并封闭出口。  
- 玩家可独自走到出口，但**帮助林共同离开**才是任务目标。  
- 首版不做七日循环、行动点、最终随机成功率。

## 3. 核心玩法与通关

### 玩法循环

探索（记录异常）→ 共同验证（可观察小实验）→ 反问与主动行动 → 说服 → 共同逃离。

### 通关条件（须同时满足）

1. 在 **E1、E2、E4、E5** 中亲自验证至少 **3** 条不同事实线索，**必须含 E5**（E3 不计数）。  
2. `route_confirmed == true`。  
3. **C1、C2、C3** 均已解决，且 `escape_agreed == true`。  
4. 两人在 **18:00 前**进入出口区域。

最小完整流程：**E1 + E4 + E5**。无随机通关判定。

### 时间规则

- 游戏内 **17:00 → 18:00**；探索与实验推进时钟。  
- **打开对话后**暂停时钟与场景动作；关闭后恢复。  
- 目标体验约 10–15 分钟（阅读会延长）。  
- 18:00 整不接受新通关；重开=重玩。

### 说服失败与恢复

- 同意逃离前最多 **一次** 暂时退开；可用「恢复交流」按钮。  
- 退开不清除证据或已解决顾虑；同意后不可再 withdraw 阻断任务。

## 4. 事实线索系统

| 线索 | 验证方式 | 说明 |
| --- | --- | --- |
| **E1** 隐藏摄像头 | 林换位，镜头跟随 | 证明秘密观察 |
| **E2** 广告屏后台 | 重现与林动作关联的后台信息 | 可补充，非最小集必需 |
| **E3** 结婚照 | 讨论细节 | **仅叙事**，不计入门槛 |
| **E4** 自动广播与预测 | 登记预测 → 启动序列 → 改道验证 | 两步成功才计 1 条 |
| **E5** 布景背面与路线 | 开维修门看支架/通道，再确认禁路 | 强证据 + 路线依据 |

林验证第一条线索后，每局最多 **一次** 主动检查机会。

## 5. 状态模型（四个独立维度）

| 字段 | 含义 |
| --- | --- |
| `verified_evidence` | E1/E2/E4/E5 集合；仅完成事件写入 |
| `concerns` | C1/C2/C3 → `open` / `resolved` |
| `cooperation_mode` | `talking` / `withdrawn` / `following` |
| `escape_agreed` | 布尔；满足硬条件后由程序写入 |

退开不会抹去知识；角色台词不能覆盖权威状态。

### 固定顾虑

| ID | 主题 | 程序检查要点 |
| --- | --- | --- |
| **C1** | 受控事实 | ≥3 条事实含 E5；引用真实输入 |
| **C2** | 隐瞒与信任 | 承认参与骗局并解释动机 |
| **C3** | 离开选择 | `route_confirmed`；尊重决定，不接受空白通关 |

首版顾虑 `resolved` 后本局不重开；模型不能新增阻碍性 ID。

## 6. 技术架构：LLM × Unity

```text
场景状态与玩家输入 → 模型提议 → 程序校验 → 场景执行 → 完成事件写状态 → 下一轮
```

**Unity 持有权威事实。** 模型输出字段：`dialogue`、`action`、`target_id`、`concern_id`、`concern_status`、`basis_turn_id`。  
合法动作：`reply` | `follow` | `inspect` | `withdraw` | `agree_escape`。

服务端保管 API 密钥；调试面板展示输入、原始输出、接受/拒绝原因与执行后状态。

## 7. 范围与交付

### 首版范围

一个住宅 + 门外小区域 + 短禁路；一个 AI 角色；约 5 条线索；文字与快捷指令；跟随/检查/一次主动反应；可恢复拒绝；截止时钟；共同逃离与超时结局；运行日志。

### 首版不做

VR、语音、多角色、战斗、追逐、开放世界、七日循环、随机通关。

### 最终交付（PRD §10）

- 约 5 页 PDF 报告 + 源码 ZIP（无密钥）  
- 5–7 分钟实际运行视频（YouTube Unlisted，≥2 情境，展示真实 LLM）  
- 第 14 周现场 POC 演示与个人问答
