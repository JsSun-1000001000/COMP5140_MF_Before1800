# 《18 点之前》：最后一次送信

本轮按时间顺序合并三份材料：早期 proposal 提供住宅、片场和限时调查框架；E4 后交接确定已有镜头与电视实验；最新小组讨论决定信使的最后一场戏、伪造回信、关系与自主选择。冲突时采用最新讨论。具体蓝杯子、阿禾明信片与日记文字是本轮为试玩补写的内容，可继续由小组调整。

## 在这台 Mac 上玩

双击仓库根目录的 **Play-Before1800.command**。它会启动或复用本机对话服务，再打开 `Builds/Before1800-Mac/Before1800.app`。首次系统可能询问是否允许打开本地生成的程序；正常确认即可，无需关闭系统安全设置。现有模型配置已保存在仅本机可读、Git 忽略的 `service/.env`，没有放入游戏客户端。

启动页先说明玩家身份、未寄出的原信与回信矛盾、可选择的玩法。右上角“声音与语言”可切换中文和英文，并调总音量、音乐、林的声音和语音开关。模型品牌与开发编号不显示给玩家。等待时保留上一句，在同一对话区显示林正在思考；可以取消，输入会保留。网络出错保留输入并提示重试，不会把预写对白冒充模型回复。

| 操作 | 按键 / 方法 |
| --- | --- |
| 移动与看向物品 | WASD 移动；鼠标或方向键转动视角 |
| 交谈、阅读、操作装置 | 面对目标按 E |
| 自由对话 | 走近林交谈，在输入框输入；发送后等回复 |

一局有约 12 分钟主动探索时间。阅读、对话、模型等待和菜单会暂停游戏时间，便于慢慢说清楚。结局后可重开新的一局。

## 第一次试玩建议

1. 查看茶几上的原信和新回信，再问林她为什么起疑。原信属于她；她谨慎时会自己查看，信任恢复后才允许玩家代读。
2. 自由表达你的选择。可以解释、坦白、闲聊，最后照常告别；这一条有完整结局。
3. 想继续调查时，可以说“你能到电视上方的镜头前看看吗？”林决定过去后，结束交谈，跟着她观察。实际装置验证会写入手记，仅说“我查过了”不算完成。
4. 电视实验先登记预测，再请林到电视前；按现场提示启动、点播、改口。前门旁黄铜卡扣可打开墙板，邀请林亲眼观察支架和制作编号；地面金线处还能独立检查通道。
5. 门边写字台有演员日记，茶几有旧友明信片。你独自读过的内容不会自动传给林；在她身旁递给她，或请她自己看。日记能表达过去的心意，不能保证门外一定能团聚。
6. 最后谈清事实、你对伪造回信的责任和她眼前的未来顾虑。她可以追问或提出条件。获得自愿同行之后，关闭对话，站到前门金线附近并给她留出位置；等她走到门边，再按 E 选择一起离开；也可以尊重她暂时留下，或独自离开。

音乐为本轮合成的原创轻声键盘与低音氛围，另有室内环境、两人的脚步、翻纸、交互、事实确认与结局提示音。语音播放时音乐自动降低。林的实际回复使用本机 Kokoro v1.1 中文/英文神经语音朗读，声音强弱驱动现有面部的 A 口型；当前不是逐音素嘴型，也不等于真人配音。声音设置提供“试听音乐”“试听音效”“试听人声”三个独立按钮。

## LLM 实际负责什么

Unity 提供有来源区分的现场观察、可达物品、已经执行的动作、林自己的背景，以及本局已接受对话的逐字记忆。模型理解玩家自由表达，决定回应、跟随、亲自查看、短暂退开、回应顾虑或自愿同行。实际走动和阅读会再改变下一轮它能知道的内容；驻足物品且被林看见，也能触发她主动发问。

补写的林是一个有自己生活的年轻人：喜欢修书，想开小工作室，曾被父母回信劝退课程；她也会拖延、说小谎，对被替自己决定很敏感。十类普通场景物件分别有独立往事：沙发、书架、植物、餐桌、鞋、灯、镜子、冰箱、椅子和厨房窗。对准物品互动或被她看见长久驻足，可以开启真实模型对话；不写入关键线索进度，也不要求把回忆全收集才通关。

同一张日记，未分享时她不能引用正文；分享后她可以谈演员的心意；玩家早先隐瞒过时，她还可以追问为何现在才告诉她。事实门槛、碰撞、导航与结局条件由游戏检查，模型不能靠一句台词生成证据或强迫同行。自然语言建议按钮也发送给真实模型，不直接替她作情感决定。

记忆只在当前一局生效，保留开场与近期逐字对话，长局中间部分会被裁减。不同表达并不保证相同回答。当前是可试玩的单场景版本，未加入跨局存档或长篇演员支线。角色语音已改用本机神经模型，不再调用 macOS 的系统声音；迁移机器请看 service/VOICE-NOTICES.txt 和 setup_voice.py。切换语言更新界面与新的模型回复，已发生的对话不会被重新翻译或改写。

Mac 独立游戏已构建并人工走通完整调查路线（2026-11-24）：从中文标题和开场介绍开始，对照原信与回信；通过真实模型对话让林亲自查看原信、镜头和电视；登记新闻预测，完成电视点播与改口；打开前门旁墙板，让林实际走到观察点看清支架和制作编号；独立检查出口通道，阅读并递交演员日记。手记确认镜头、电视、布景和通道四项事实后，继续用真实模型完成事实串联、认责和未来顾虑对话。自由输入咖啡馆、旅馆和由林决定下一步的具体计划后，她明确答应同行并提出自己检查房价与门锁的条件。关闭对话后，她实际走到门边，选择一起离场，出现“一起走出镜头”结局，离场时间为 17:38:16；随后重开并返回中文启动页。

## 2026-11-24 体验问题修复

- 音频：用户日志出现默认音频设备变化后初始化失败。音乐改为真实导入的 48 秒原创立体声资源；设备变化会重建运行时音效并重启循环，同时检测意外停止。Unity 回归实际检查 AudioSettings.Reset 后 AudioListener 输出波形。游戏日志会记录 Music PCM active，独立播放器也检查实际音乐波形，而非仅检查资源存在。
- 配音状态：修复试听人声后实际台词无法继续播放的问题，并检查取消、重试与新一轮语音不会互相覆盖。
- 配音：离线 Kokoro v1.1，中文 zf_001、英文 af_maple，不需要额外语音 API 密钥。真实回复语音在独立播放器播放成功；首次加载比热运行慢。仍是合成声音，口型按幅度变化。
- 对话：日常以一两句为主；长篇坦白不再自动触发长篇回复。模型仍会有输出差异。新增权威亲见事实提醒，修复模型否认已完成镜头实验而要求重复调查的问题。真实 C1 复测成功，C2 短回复复测成功。
- 界面：缩小底部聊天区域，常用建议压到三个；等待保留在同一对话框。新增两封信并排比较、六步指引、目标距离和 H 玩法帮助，中英文同步。比较只展示林主动念出的一句，不越过私人原信的阅读权限。
- 导航：玩家挡路时等待让路，临时遮挡视线时等待看清；重新规划后才报告真正无法到达。住宅内失败改为短暂提示，不再用“林停下了”全屏暂停。物理控制器九处目标可达、让路后继续的回归均通过。独立播放器已实际看到林接受邀请并走到镜头观察点。

本轮验收：Unity 73 通过、0 失败、1 跳过；服务 98 通过。真实模型覆盖日常中文/英文、认责、事实理解、未来顾虑、主动同行等请求。最新独立游戏已人工完成从标题、信件对照、全部调查、日记分享、最终对话、门口同行到“一起走出镜头”结局的完整流程。门口修复经过三个玩家站位的实际场景行走回归，并在上述独立游戏通关中验证；其他结局条件由 Unity 回归补充覆盖。
