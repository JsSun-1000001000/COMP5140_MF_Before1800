## 2. 开场 15 分钟

1. `git pull origin main`  
2. Unity **2021.3.3xf1** 打开工程；场景优先：  
   - 住宅：`Assets/Before1800Home/PartB_Residence.unity`（E1 + E4）  
   - 灰盒：`Assets/Before1800B/PartB_Greybox.unity`（E1 + E4 + **E5/路线**）  
3. 可选 LLM：`service/start.ps1`（在 `service/` 目录）→ Play 后 **F2** 开 DeepSeek。  
4. 自测 E4：对话登记预测 → 去电视 → E/F 启动 → 点播 → 改口 → 手记出现 E4。

**不要**提交本机 `Packages/packages-lock.json` 里把 registry 改成 `file:embedded` 的变动；**不要**把含密钥的 `service/.env`、`service/logs/` 推进仓库。

## 3. 建议下一位优先顺序

### P0 — 能完整通一局（建议灰盒收口）

1. **E5 + `route_confirmed` 可重复验收**（灰盒已有站；补提示/失败复位若还不顺）  
2. **同一局里串 E1→E4→E5**，确认 `verified_evidence` 为集合、不可语言伪造  
3. **C1 / C2 / C3 状态机**（C2 已有模型解决路径；C1 需 ≥3 条含 E5；C3 需路线）  
4. **`escape_agreed` + 出口触发**（两人同在、18:00 前；超时失败结局）

### P1 — 演示与文档

5. 按 `docs/PartC_本地演示.md` 固定 2+ 情境；录 5–7 分钟 Unlisted YouTube（露出真实 LLM in/out）  
6. 5 页 PDF：概述、架构、LLM、测试/局限、贡献  

### P2 — 有余力再做

7. 住宅是否另挂 E5（空间紧，先前已撤掉；可用灰盒通关或双场景）  
8. E2 广告屏、E3 结婚照（非最小集）  
9. 把 E4 的预测/点播/改口结果更完整地打进 Part C 请求上下文（见交接表）

详细日程仍以 `docs/开发计划_4人小组.md` 为准。
