# 《18 点之前》住宅试玩

玩家扮演林的朋友。林相信这栋住宅就是他的家，玩家却知道这里是片场，因为自己也是参与骗局的演员。完整游戏要求玩家在 17:00 到 18:00 之间带林查验证据、坦白自己的隐瞒、回应林的顾虑，并取得林的同意，一起离开片场。

玩家从原 `Scene 3 - WeTogether` 的客厅出发，一侧通厨房，另一侧通卧室，浴室入口在卧室内。入户门是这段试玩的边界。米塔的模型扮演林。玩家可以在同一套住宅里体验摄像头跟踪实验、客厅电视预测实验和挂钟支线「少走的一秒」。[策划目标与素材清单](PRD_Before1800_RevisedV2.md)

## 进入住宅

在 Unity 2021.3.35f1 中打开 `Assets/Before1800Home/PartB_Residence.unity`，点 **Play**。点击「开始探索」或按 **Enter**。用 **WASD** 移动、鼠标环顾。

要生成 Windows 试玩包，在 Unity 选择 **Before 18 → Build residence Windows player**。输出在 `Builds/Before1800-Clock`。双击 **Before1800.exe** 可离线玩完整段挂钟剧情。双击同目录的 **Play-With-Lin.cmd** 可让林用 DeepSeek 回应自由输入的台词。在线版启动时会检查本机 Python 环境，缺少可用密钥时在启动窗口隐藏输入。关闭游戏会一并关闭这次启动的网关。[对话服务说明](../service/README.md)

## 少走的一秒

1. 看向沙发前茶几上的黑色遥控器，按 **E** 拿起。遥控器背面写着「厨房 · 重播」。
2. 去厨房，对准挂钟按 **E** 听完一轮，再按 **E** 重播。保持视线，看秒针走过三格、退回，再走过同样的三格。
3. 找林谈挂钟，选「跟我去厨房，第三拍时看秒针。」一起走到钟前，给林让开一点，再次重播。中途遮挡视线，可以调整站位再试。
4. 林亲眼看完后，会追问你怎么知道该按哪颗键。你可以承认排练过，也可以岔开话题。下次再谈起时，林会记得你的回答。客厅电视还会短暂亮出一张重拍提示卡，走近按 **E** 可以把它写进手记。若已登记电视预测，提示卡会等这一轮实验结束再显示。

玩家独自看到的异常留在自己的手记里。林参与的邀请、亲眼看见的三拍和你对遥控器的解释会进入林的对话上下文。挂钟支线独立于正式证据和结局判定。

## 住宅内的操作

| 在住宅里 | 操作 |
| --- | --- |
| 开关三扇室内门 | 靠近门板或门框，看向它，站定后按 **E** 开关。门扇碰到人会等候。 |
| 和林交谈 | 看向附近的林，出现提示时按 **E**。用鼠标选一句话，或用 **Tab / Shift+Tab** 切换控件、**Enter** 确认。 |
| 林主动收住话题 | 在线对话中，林还想追问时，输入框会留在屏幕上。她想独处或决定亲自查看物品时，输入框会收起，最后一句说完便恢复探索。按 **Esc** 可以提前返回。之后靠近林按 **E**，她仍然记得刚才的谈话。 |
| 一起去看镜头 | 选镜头相关话题，点「一起去看看」。对话收起，林走向第一个观察点。 |
| 真实跟踪写入 E1 | 镜头开场起就会跟着林转。林到第一个观察点后对准镜头按 **E**，请她换到第二个点并确认跟随；锁定后手记才出现 E1。 |
| 客厅电视预测 | 在谈话中登记节目，带林到电视前启动序列，验证点播再改播。详见[三个可玩例子](E4_电视预测实验.md)。 |
| 跟随与停下 | 在谈话中选「和我一起走走？」再选「跟我来。」如果门关在两人之间，林会等候，重新开门就能跟上。 |
| 查看和记录发现 | 自己走近电视上方的镜头，对准按 **E** 可先记入「玩家发现」。按 **J** 翻开手记。 |
| 暂停与离开 | 阅读、输入和等待回复时，时钟和人物一起暂停。**Esc** 先收起当前一层。探索中按 **Esc** 打开菜单，重新开始须再次确认。 |

摄像头需要完成两个观察点的跟踪确认，电视需要完成预测和改播。手记分别记录 E1、E4。维修门、布景背面和出口路线可在[灰盒场景](PartB_灰盒验收.md)体验。

## 美术和玩法如何配合

住宅使用原场景的家具网格和贴图。三根钟针和茶几遥控器从原模型中拆出，住宅导航连接四个房间。室内门绕原门轴转动。米塔使用原骨架、服装和贴图，并对住宅版本的服装蒙皮做了适配。

原住宅有多种步态。试玩采用其中的 `Walk With Controller`，米塔的手臂自然垂下，随左右脚交替摆动。站定时过渡到原住宅的双手叠放待机 `Mita Idle_2`。待机副本校正了导出骨骼的旋转顺序，使双脚落在地面。人物在直路上以每秒 1.1 米的速度行走，起步时逐渐加速，转向和靠近目标时放慢脚步。步频随实际位移调整。B 决定林往哪里走，开对话或菜单时同时暂停移动、动画和时钟。[原工程的走路片段](https://github.com/yenichw/MiSide-Demo-Unity-Project/blob/main/Assets/AnimationClip/Walk%20With%20Controller.anim)

靠近林并站在她面前，她会看过来，轻轻抬一下眉，随后恢复平常的表情。转去检查设备时，视线先朝向路径，头和身体随后转动。住宅版保留原头模的眨眼、眼睛高光和腮红，脸、脖子和手使用各自的原卡通材质。百褶裙的腰带跟随髋部，左右下摆随对应大腿移动。打开对话时，角色动作和表情一同暂停。[原眨眼动画](https://github.com/yenichw/MiSide-Demo-Unity-Project/blob/main/Assets/AnimationClip/Blink.anim)
