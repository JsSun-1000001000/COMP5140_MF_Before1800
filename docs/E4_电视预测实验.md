# E4 客厅电视预测实验

按 PRD §4.2：**先锁定预测 → 启动序列 → 预测命中 → 改道干预 → 两步成功才写入 E4**。  
本项目载体改为**客厅电视**：林想看什么，画面就切什么；但只「看着切」不够，必须走完两步。

| 固定 event_id | 节目 |
| --- | --- |
| `tv_news` | 新闻 |
| `tv_cartoon` | 动画片 |
| `tv_weather` | 天气预报 |

目标 ID：`living_tv` → 证据 **E4**。

---

## 操作流程

1. 与林对话 →「关于客厅这台电视」→ **登记预测**（三选一，启动后不可改）。  
2. 「一起去客厅电视前验证」→ 林走到 `e4_tv_observe`。  
3. 对准屏幕按 **E / F**：  
   - 启动序列（开机默认节目 ≠ 预测，以便例 3 可点错）  
   - 请林点播**预测节目** → 步骤 1  
   - 请林**改口**点播另一节目 → 步骤 2 → 写入 E4  
4. 对话打开时世界暂停；林离场或预测不符 → 不计 E4，可重新登记重试。

---

## 三个例子（已写入可玩选项）

### 例子 1：新闻 → 改口天气

1. 登记：「启动后会播新闻」→ 锁 `tv_news`  
2. 林到场，启动序列  
3. 点播新闻 → 画面变蓝「新闻」→ **步骤 1**  
4. 改口点播天气预报 → 画面变绿 → **步骤 2** → **E4**

对应改道映射：`News → Weather`。

### 例子 2：动画片 → 改口新闻

1. 登记：「启动后会播动画片」→ 锁 `tv_cartoon`  
2. 启动后点播动画片 → **步骤 1**  
3. 改口点播新闻 → **步骤 2** → **E4**

对应改道映射：`Cartoon → News`。

### 例子 3：预测失败后重试

1. 登记：「启动后会播天气预报」→ 锁 `tv_weather`  
2. 启动后，在对话里**故意点播新闻**（与预测不符）→ **步骤 1 失败**，不计 E4  
3. 重新登记天气预报（或另选例 1/2）→ 启动 → 点对 → 再改口（天气成功路径改口为动画片）→ **E4**

---

## 验收要点

| 检查 | 期望 |
| --- | --- |
| 启动前未登记 | 不能开始序列 |
| 启动后改预测 | 拒绝 |
| 只完成步骤 1 | `verified_evidence` 仍无 E4 |
| 步骤 1+2 | 写入 E4；手记出现确认句 |
| 点错节目 / 林离场 | 不计；可复位 |
| 语言声称「我猜到了」 | 不能补写 E4 |
